Privacy Policy

Last updated: 4 October 2026

Server Valet ("Server Valet", "the Bot", "we", "us", or "our") is a Discord bot designed to provide server management, moderation, community and administrative tools.

This Privacy Policy explains what information Server Valet may access, how that information may be used, how it may be stored, and the steps we take to minimise the information we retain.

1. Information We May Access

Depending on the permissions and features enabled by a Discord server administrator, Server Valet may access information made available through Discord's API.

This may include:

  • Discord user IDs
  • Usernames and display names
  • Server membership information
  • Server join dates, where available
  • Roles assigned to members
  • Server, channel and role IDs
  • Server and channel names
  • Information required to perform moderation actions

2. Activity Information

Features such as member profiles and inactivity tracking may require Server Valet to record limited activity information.

This may include:

  • The date and time of a member's activity
  • The channel in which activity occurred
  • Message or activity counts
  • The date of a member's most recent activity

Activity information is used to provide server-management features such as activity statistics, inactivity tracking and staff-facing member profiles.

3. Moderation Information

When Server Valet is used for moderation, it may store information necessary to maintain a moderation record.

This may include:

  • The Discord ID of the affected member
  • The Discord ID of the staff member performing the action
  • The type of moderation action
  • The selected reason
  • A staff-provided moderation note
  • The date and time of the action
  • A unique moderation or action identifier
  • Relevant server or channel identifiers

This information exists to provide an auditable moderation history for the Discord server and its authorised staff.

4. Message Content

Discord may provide message content to Server Valet when required by a feature and when the appropriate Discord permissions and intents are enabled.

Server Valet is designed to minimise the collection and retention of message content. Where a feature only requires information such as a timestamp, channel ID or activity count, the Bot is designed to use that information rather than permanently storing the full message.

Server Valet does not use users' Discord messages to train artificial intelligence models.

5. Information We Do Not Intentionally Collect

Server Valet is not designed to intentionally collect information such as:

  • Passwords
  • Discord authentication credentials
  • Payment card information
  • Precise physical location
  • Private messages unrelated to the Bot's functionality
  • Information from outside Discord unless a future feature specifically requires it

6. How Information Is Used

Information accessed or stored by Server Valet may be used to provide features including:

  • Staff member profiles
  • Activity and inactivity tracking
  • Moderation records
  • Warnings and bans
  • Ticket management
  • Server administration
  • Events and polls
  • Nickname management
  • Notifications and other server-management functions

7. Data Minimisation

Server Valet follows a data-minimisation approach.

We aim to collect and retain only the information reasonably necessary for the features provided by the Bot.

Where possible, Server Valet will use identifiers, timestamps, counts and other limited information instead of retaining full message content or unnecessary personal information.

8. Data Sharing

We do not sell, rent or trade user information to third parties.

We do not operate advertising networks or data-broker services.

Information may be visible to authorised Discord server staff where the relevant Server Valet feature is designed to provide staff-facing information.

Information may also be processed by infrastructure or service providers required to operate Server Valet, such as hosting, database or other technical service providers.

9. Server Administrator Responsibility

Server administrators decide whether to install Server Valet and which permissions and features it receives.

Server administrators are responsible for configuring the Bot appropriately for their community and for ensuring that their use of Server Valet complies with applicable laws, Discord's rules, and their own community policies.

10. Data Retention

Information is intended to be retained only for as long as it is reasonably necessary to provide the relevant Server Valet feature, maintain server administration records, or comply with legitimate legal or operational requirements.

Retention periods may vary depending on the type of information, the feature using it, and the configuration of the server.

11. Removing Server Valet

A server administrator may remove Server Valet from their Discord server at any time.

Removing the Bot prevents it from continuing to access information from that server through Discord.

Previously stored information may not be deleted immediately where it is required for legitimate moderation, security, legal or operational purposes. Where appropriate, stored information may be deleted in accordance with our retention practices.

12. User Requests

If you have questions about information associated with your use of Server Valet, or believe information should be corrected or deleted, you may contact us using the address below.

Requests may require sufficient information to identify the relevant Discord server, account or information concerned.

13. Security

We take reasonable technical and organisational measures to protect information processed by Server Valet.

However, no online service or method of electronic storage can be guaranteed to be completely secure.

14. Children's Privacy

Server Valet is intended to operate within Discord communities and does not intentionally collect information from children for the purpose of profiling or advertising.

Server administrators are responsible for ensuring that their servers and use of Server Valet comply with applicable age, privacy and child-safety requirements.

15. Changes to This Privacy Policy

We may update this Privacy Policy when Server Valet gains new features, changes how information is processed, or when required for legal or operational reasons.

The latest version will always be made available on this website.
